Parameter Definitions and Units

All time and concentration units must remain consistent within a simulation
N₀: Consumer Initial Biomass (biomass).
mᵢ: Maintenance/mortality loss rate of consumer i (time⁻¹), acting independently on Nᵢ.
R₀: Initial Resource Concentration; S: External Feed Concentration (resource concentration).
Dα: Resource α supply/Dilution Rate (time⁻¹); D=0 represents batch culture, D>0 represents continuous supply.
cᵢα: Maximum uptake rate of resource α by consumer i (resource·biomass⁻¹·time⁻¹).
Kᵢα: Monod Half-saturation constant; when Rα = Kᵢα, the uptake rate is half its maximum.
Yᵢα: Biomass Yield (biomass/resource), Converts resource uptake flux into consumer growth.
N, M, Total Time, Output Interval: control Number of Consumers, Number of Resources, integration endpoint, and CSV/plot sampling frequency.

METHODS & ALGORITHMS

Implementation, Model, and Solver Details

1. Mathematical Model

Consumers take up multiple resources using Monod kinetics. The uptake flux is:

uᵢα=cᵢαRα/(Kᵢα+Rα)

Consumer growth is determined by biomass yield Y, whereas m represents independent maintenance or mortality loss. Resources are replenished through the supply term D(S−R) and depleted by consumer uptake.

2. Numerical Solution

The coupled N+M ordinary differential equations are integrated using the classical fourth-order Runge–Kutta (RK4) method. A conservative internal step size is selected from the output interval and total duration, and small negative values caused by numerical error are truncated to 0.

3. Batch and Continuous Culture

When D = 0, no external resource is supplied, corresponding to closed batch culture. When D > 0, resources approach the feed concentration S, representing continuous culture or an open environment. Consumers do not wash out with dilution in the current equations; add DᵢNᵢ as an additional loss term to represent chemostat outflow.

4. Parameterization Guidelines

Parameters must use compatible units. The time unit determines the scales of m, D, and c, while resource and biomass units jointly determine c and Y. Validate parameter magnitudes in a single-resource, two-consumer system before increasing N and M.

5. Random Simulation

All parameters are generated independently for each replicate. Normal random variables are generated using the Box–Muller method, and truncated distributions use rejection sampling with a safe fallback. All parameters and trajectories are written to UTF-8 CSV files to support reproducibility.

Scope and Limitations

This tool is suitable for teaching, hypothesis testing, and experimental design. Some parameter combinations may cause rapid resource depletion or numerical stiffness; use consistent units, check parameter magnitudes, and validate results through sensitivity analysis and independent experiments. The model does not explicitly represent metabolite secretion, cross-feeding, resource transformation, spatial structure, or evolution.
