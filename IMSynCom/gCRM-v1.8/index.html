Yᵢα：生物量产率（biomass/resource），将资源摄取通量换算为消费者增长。
N、M、总时间、输出间隔：分别控制消费者数、资源数、积分终点和 CSV/绘图采样频率。

METHODS & ALGORITHMS

制作方法、模型与求解说明

1. 数学模型

消费者以 Monod 动力学摄取多种资源。摄取通量为：

uᵢα=cᵢαRα/(Kᵢα+Rα)

消费者增长由产率 Y 转换，m 为独立维持/死亡损失。资源由稀释供给项 D(S−R) 补充并被消费者消耗。

2. 数值求解

联立的 N+M 个常微分方程采用经典四阶 Runge–Kutta（RK4）积分。内部步长根据输出间隔和总时长自适应选取保守值；数值误差导致的微小负值截为 0。

3. 批次与连续培养

D=0 时没有外源补给，对应封闭批次培养；D>0 时资源趋向进料浓度 S，对应连续培养或开放环境。当前式中消费者不随稀释流出，如需恒化器出流，可把 DᵢNᵢ 作为额外损失加入。

4. 参数设置原则

参数必须使用相容单位：时间单位决定 m、D 和 c 的速率尺度，资源与生物量单位共同决定 c 和 Y。建议先用单资源、双消费者的小系统校验量级，再扩展 N 与 M。

5. 随机模拟

每次重复独立生成全部参数。正态随机数由 Box–Muller 法产生；截断分布采用拒绝抽样并设置安全回退。所有参数和轨迹共同写入 UTF-8 CSV，便于复现。

适用范围与局限

本工具适合教学、假设检验和实验设计。参数组合可能产生极快耗竭或数值刚性；应统一单位、检查参数量级，并通过敏感性分析和独立实验验证。模型未显式描述代谢物分泌、交叉喂养、资源转化、空间结构和进化。
