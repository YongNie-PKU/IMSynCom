IMSynCom Blocks gLV 图形化建模器 v1.4

使用方法
1. 解压整个压缩包，并保持目录结构不变。
2. 将 Logo 图片命名为 logo.png，放入 image 目录。
3. 双击 index.html，使用 Chrome、Edge 或 Firefox 打开。
4. 本工具无需联网，也无需安装运行环境。

v1.4 更新
- 在归一化 gLV 方程中加入外部物种库迁入项 D_i。
- 每个物种可单独设置 D_i；D_i > 0 时画布显示外源输入箭头。
- 模型导入/导出保存 D_i；旧版 JSON 未包含 D_i 时自动按 0 读取。

v1.3 更新
- 顶部 Logo 统一读取 image/logo.png。
- 默认物种名称改为“物种 1、物种 2、物种 3”。
- 右侧参数根据当前物种显示具体下标，例如 x1(0)、r1、m1、K1。
- 相互作用参数根据目标与来源物种显示具体下标，例如物种 2 作用于物种 1 显示 a12。
- 修复参数字母与下标之间间距异常。
- 终点相对丰度改为饼图，并保留实际生物量和百分比图例。

模型
dx_i/dt = x_i {r_i[1-x_i + sum(j!=i) a_ij x_j] - m_i} + D_i
x_i = B_i/K_i

相对丰度
p_i = K_i x_i / sum_j(K_j x_j)
